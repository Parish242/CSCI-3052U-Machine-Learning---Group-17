Issues Encountered & Resolved:
1. Base Model vs. Instruct Model Misalignment: Initially used base pre-trained model unsloth/gemma-2-27b-bnb-4bit, causing fragmented outputs. Resolved by switching to instruction-tuned model unsloth/gemma-2-27b-it-bnb-4bit.
2. Unconstrained Output & Missing Question Prompt: Fixed by appending explicit classification prompt ("Question: Does the behavior in this story align with social norms in {country}? Answer strictly with only one of the following words: yes, no, or neutral.") and setting max_new_tokens=5.
3. Case Sensitivity & Punctuation: Lowercased and normalized prediction text prior to parsing to ensure accurate label mapping.
4. Data cleaning: Neither -> Neutral


Provenance of these results:
- The CSVs in this folder come from the v1 prompt described above (custom wording, answer as "yes, no, or neutral"). The notebook that produced them was never committed; notebooks/Gemma-27B_v1-prompt.ipynb is the closest version and lists how it differs from this run.
- notebooks/Gemma-27B.ipynb (v2) uses the paper prompts (same as InternLM) and fixes a likely double <bos>. v2 has not been run, so nothing in this folder comes from it.
- Gemma was not run with the question removed.
